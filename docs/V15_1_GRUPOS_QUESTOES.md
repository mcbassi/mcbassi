# V15.1 — Grupos com lista de questões

## Fluxo alinhado ao legado

- `grupos_nome`: cadastro principal do grupo
- `grupos_prioridades`: relação entre grupo e perguntas
- `form_fields`: catálogo das perguntas do questionário

## O que a tela faz

- lista os grupos existentes
- abre um grupo para edição
- mostra todas as perguntas de `form_fields`
- marca as perguntas já pertencentes ao grupo
- salva substituindo a lista atual de perguntas do grupo
- cria e apaga grupos
